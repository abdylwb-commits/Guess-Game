# Guess-Game


🎲 Guess A Number Game - 1 to 50

*GUESS A NUMBER BETWEEN 1 TO 50*
Ye mera Python me bana hua chota sa Number Guessing Game hai. Computer 1 se 50 ke andar ek secret number sochta hai, aur tumhe usko guess karna hai.

Developed by *Rana Abdul Wahab*

✨ Features
- Computer har dafa naya random number sochta hai
- Agar guess bara ho to kehta hai "THORA NECHA SOCHOO"
- Agar guess chota ho to kehta hai "THORA UPPER SOCHOO"
- Sahi guess par kehta hai "MUBAREK HO NUMBER MIL GYA"
- Aakhir me sahi number bhi bata deta hai

🚀 Kaise Chalayen (How to Run)
1. Python install karein
2. File ko download karein guess_game.py
3. Terminal / CMD me ye likhein: python guess_game.py

🧾 Example - Game Kaise Chalega
TUMHARA GUESS : 30
THORA UPPER SOCHOO
TUMHARA GUESS : 45
THORA NECHA SOCHOO
TUMHARA GUESS : 40
MUBAREK HO NUMBER MIL GYA
NUMBER THA : 40

🛠️ Technology
- Language: Python
- Concept Used: random.randint, While Loop, if Condition
